# Java 后端面试复习资料库

一套面向 **Java 后端开发工程师**的系统化面试复习资料：按能力递进分为 8 个阶段，共 **38 篇分册 + 1 份路线总纲**，覆盖 Java 基础、并发、JVM、MySQL、Redis、Spring 全家桶、中间件、分布式与架构、计算机基础、工程化，以及简历/场景题/谈薪等面试实战内容。

- **适用人群**：社招 1~5 年 Java 后端（以 3~5 年为主），校招与转岗同样可用（按需调整深度）
- **目标岗位**：大厂 / 中大型互联网公司 Java 后端开发
- **配套周期**：4 周冲刺版、8 周标准版、12 周扎实版（见总纲第 4 节）

---

## 从这里开始

1. **先读** → [`docs/00-复习路线总纲.md`](docs/00-复习路线总纲.md)
   里面有：岗位能力模型、技术栈权重表、**自评矩阵**（找出你的薄弱模块）、三种周期的排期表、每日时间盒、进度追踪表、冲刺清单。
2. **再诊断** → 用 3 天时间做完自评矩阵 + 简历初稿，确定复习重心。
3. **然后开打** → 按阶段顺序推进，每篇文档走同一个闭环：
   `扫知识地图 → 精读原理 → 合文档自问自答 → 做自测题 → 错题进错题本`

> **使用铁律**：只看懂不算过关。判断标准是——合上文档，能在白纸上画出流程、讲出阈值数字、说出失效场景与替代方案。

## 每篇文档的统一结构

所有分册使用同一骨架，便于按同一节奏推进：

| 小节 | 用途 |
| --- | --- |
| `0. 知识地图` | 知识点清单 + 重要度 + 常考形式（八股/场景/手写/调优/源码追问） |
| `x.1 核心原理` | 讲清 why 与 how，带阈值、源码要点、版本差异 |
| `x.2 面试问答` | Q/A 形式，答案是"能直接背"的：结论 → 原因 → 边界 |
| `x.3 高频追问与陷阱` | 面试官的第二三层追问 + 常见错误回答 |
| `x.4 示例` | 代码 / SQL / 配置 / 命令，短小可直接复制 |
| `x.5 一句话速记` | 可背诵的结论短句 |
| `自测题` | 12~20 题，附答案要点 |
| `背诵卡片` | 30~40 条一行速记，面试前 30 分钟扫读 |

## 进阶用法

- **按岗位定制**：拿到 JD 后，用总纲 [1.1 技术栈地图](docs/00-复习路线总纲.md) 对照，把 JD 提到但本资料权重较低的点（如 Flink、大数据、Go）单独补一份笔记。
- **按项目定制**：简历上写了的每一项技术都必须能答到 L3（实践/排查）层，答不了的要么补要么从简历删掉。
- **按面试反馈迭代**：每次面试后填一份复盘表（总纲 5.4），把暴露的盲区补进对应分册的错题本。
- **当作团队复习资料**：8 个阶段目录可直接分给不同人准备技术分享，每篇文档的「知识地图」可直接做分享大纲。
